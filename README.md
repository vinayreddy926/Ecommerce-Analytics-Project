# 🛒 E-commerce Analytics Project

## 📊 Project Overview
This project focuses on analyzing e-commerce sales data to uncover insights about customer behavior, product performance, and revenue trends. The analysis is performed using Excel, SQL, Power BI, and Tableau.

---

## 🎯 Objectives
- Analyze sales trends and revenue growth
- Identify top-performing products and categories
- Understand customer purchasing behavior
- Detect patterns in profit and loss

---

## 🛠️ Tools & Technologies
- *Excel* – Data cleaning and preprocessing  
- *SQL* – Data querying and analysis  
- *Power BI* – Interactive dashboards  
- *Tableau* – Data visualization  

---

## 📁 Project Files
- Excel_Ecommerce_Project.xlsx → Raw & cleaned dataset  
- SQL_Ecommerce_Project.sql → SQL queries for analysis  
- PowerBi_Ecommerce_Project.pbix → Power BI dashboard  
- Tableau_Ecommerce_Project.twbx → Tableau dashboard  
- Ecommerce_Presentation_Final.pptx → Project presentation  

---

## 📈 Key Insights
- Identified top-selling products and categories  
- Analyzed monthly and yearly sales trends  
- Found high-value customer segments  
- Compared profit margins across regions  

---

## 📊 Dashboards
Power BI and Tableau dashboards provide:
- Sales overview  
- Profit analysis  
- Customer segmentation  
- Regional performance  

---

## 📌 Conclusion
This project helps businesses make data-driven decisions by understanding customer behavior and optimizing product strategies.
